📊 How we calculated this ▼
⚡ Energy Calculation

Energy (kWh) = Power (W) × Time (hours) / 1000

We use 400W base power for inference, adjusted by model size

🌍 Carbon Calculation

CO₂ (g) = Energy × PUE × Grid Intensity

PUE (Power Usage Effectiveness) is 1.2 for modern datacenters

📡 Data Sources
  • Ember Climate - Grid carbon intensity by country
  • IEA - Regional energy statistics
  • ML CO2 Impact - AI energy consumption research

⚠️ These are estimates. Actual emissions vary based on hardware, optimization, load balancing, and real-time grid conditions. We aim for directional accuracy, not precision.
